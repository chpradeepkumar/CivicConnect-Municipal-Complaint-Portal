# CivicConnect – Municipal Complaint Portal

## Project Description

CivicConnect is a web-based Municipal Complaint Portal developed to provide a simple and efficient platform for citizens to report civic issues such as garbage accumulation, damaged roads, streetlight problems, water supply issues, and drainage problems.

The system allows citizens to submit complaints by providing details such as category, description, and location. Municipal authorities can view submitted complaints, manage them, update their status, and track the progress of complaint resolution.

The main objective of CivicConnect is to digitalize the municipal complaint process, reduce manual effort, improve transparency, and provide better communication between citizens and municipal authorities.

## Key Features

- User Registration and Login
- Submit Civic Complaints
- Complaint Categorization
- Complaint Details and Location
- Complaint Status Tracking
- Admin Complaint Management
- Status Updates and Notifications

## Technology Stack

- **Frontend:** React.js
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **API:** REST API
- **Version Control:** Git & GitHub

## Project Objective

The objective of CivicConnect is to create a centralized and user-friendly platform that makes reporting and managing municipal complaints faster, more organized, and transparent.
